# 도착 칸 브리핑

도착한 칸에 **설명만** 보여 줍니다. 칸이 생활사건을 만들거나 운용을 강제하지 않습니다. 한 턴은 그대로 `시장 브리핑 → (생활사건) → 운용 1회 → 정산`입니다.

원고의 원본은 `src/data/tile-briefings.json`입니다. 한 줄 요약이 아니라, 칸마다 **서로 다른 본문 5개**를 풀로 둡니다. 도착할 때마다 시드·턴·칸 번호로 하나를 고릅니다. 같은 시드로 같은 칸에 같은 턴에 도착하면 같은 글이 나옵니다.

## 규칙

- 24칸 × 5편 = 120편. 같은 칸의 5편은 제목이 겹치지 않습니다.
- 고르는 키는 `{시드}:tile-brief:{턴}:{칸번호}` 입니다.
- 확인을 누르면 생활사건이 있는 턴만 사건 창으로 이어집니다.
- 생활 사건 칸은 표지판입니다. 실제 사건은 시드 일정(한 판 3회, 2~11턴)으로만 납니다.
- 연결 `cardId`는 기존 학습 카드입니다. 도착하면 그 카드를 해금합니다.
- 수치는 교육용 단순화입니다. 투자 권유가 아닙니다. 기준일 2026-08-10.
