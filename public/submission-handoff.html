연금로드를 제출·재실행할 때

이 페이지는 프로젝트를 다른 사람(또는 다른 AI)에게 넘길 때 쓰는 한 장입니다. 실행가능한 상태를 만드는 복붙 프롬프트, 필요한 패키지, 소스 목록을 모았습니다. 이 HTML만으로는 게임이 돌아가지 않습니다. 저장소를 받아 npm ci 한 뒤 브라우저로 엽니다.

1. 한 줄 요약

연금로드(Pension Road)는 12턴 IRP 교육용 HTML5 게임입니다. Vite + TypeScript, 서버 없음, 로그인 없음, 환경 변수 없음. 숫자는 브라우저 LocalStorage에만 남습니다.

항목값
저장소embrain82/2608_Pension_Monopoly
권장 체크아웃main 또는 태그 prod-2026-09-07-quiz-pension
런타임Node.js 22 이상 + npm (CI·Pages도 Node 22)
모듈"type": "module" (ESM)
프로덕션 의존성없음. package.json의 패키지는 전부 devDependencies
비밀·API 키없음. .env를 만들지 말 것
운영 URLhttps://pension-road.vercel.app/
저장 스키마LocalStorage 버전 6
구현 기준2026-09-06 묶음 C + 2026-09-07 퀴즈 5장 교체

브라우저에서 제목 화면이 뜨고 「바로 시작」으로 한 턴을 넘기면 실행 가능 상태입니다. 백엔드·DB·토큰을 찾지 마세요.

2. 실행가능한 상태를 만드는 프롬프트

아래 글을 그대로 복사해 다른 AI 또는 인수인계 메모에 붙이면 됩니다. 저장소에 접근할 수 있어야 합니다.

당신은 로컬에서 「연금로드(Pension Road)」를 실행 가능한 상태로 만듭니다.

프로젝트
- 저장소: https://github.com/embrain82/2608_Pension_Monopoly
- 권장 체크아웃: 브랜치 main, 또는 태그 prod-2026-09-07-quiz-pension
- 스택: Vite 7 + TypeScript 5.8 + Vitest 3. ESM. 서버리스 정적 HTML5 게임.
- 성격: 12턴 가상 IRP 교육 게임. 실제 계좌·추천·실시간 시세 없음.
- 데이터: 브라우저 LocalStorage만. 저장 스키마 v6.
- 비밀: 환경 변수, API 키, 로그인, DB, CMS 없음. .env를 만들지 말 것.
- 런타임 npm 패키지: 없음. package.json의 패키지는 전부 개발용(devDependencies).

할 일 (이 순서)
1. Node.js 22 이상이 있는지 확인한다. 없으면 22 LTS를 설치한다.
2. git clone https://github.com/embrain82/2608_Pension_Monopoly.git
3. cd 2608_Pension_Monopoly
4. git checkout main
   (고정본이 필요하면: git checkout prod-2026-09-07-quiz-pension)
5. npm ci
   (lockfile이 없으면 npm install)
6. 검증: npm run lint && npm run typecheck && npm run test
7. 개발 서버: npm run dev
8. 터미널에 나온 로컬 주소(보통 http://localhost:5173/)를 브라우저에서 연다.
9. 제목 화면 → 「바로 시작」→ 속보 카드를 넘기고 한 턴을 진행해 본다.
10. 같은 서버에서 /user-manual.html, /operator-manual.html, /submission-handoff.html 이 열리는지 확인한다.
11. 배포본이 필요하면 npm run build 후 dist/ 를 정적 호스팅한다. Vite base는 './' 이라 하위 경로도 된다.

완료 조건
- npm run test 가 통과한다.
- npm run build 가 dist/ 를 만든다.
- 브라우저에서 게임이 열리고 한 턴을 진행할 수 있다.
- 콘솔에 validateContent 오류가 없다.

하지 말 것
- .env, 서버, 데이터베이스, OAuth, API 키를 추가하거나 찾지 않는다.
- package.json에 런타임 dependencies를 새로 넣지 않는다.
- 기획안 원본(퇴직연금_브루마블형_HTML5_게임_기획안*)을 수정하지 않는다.
- 규칙을 바꾸면 public/user-manual.html, public/operator-manual.html, tests/manuals.test.ts 를 같은 작업에서 고친다.

참고 경로
- 진입: index.html → src/main.ts → validateContent() + PensionRoadApp
- 엔진: src/engine/  화면: src/ui/  콘텐츠 JSON: src/data/
- 설정: package.json, vite.config.ts, tsconfig*.json, vercel.json
- 매뉴얼: public/user-manual.html, public/operator-manual.html
- 이 핸드오프: public/submission-handoff.html

ZIP만 받았을 때

Git이 없으면 압축을 푼 폴더에서 5번(npm ci)부터 같습니다. package-lock.json이 있어야 버전이 고정됩니다.

3. 사람용 체크리스트

  1. Node.js 22 확인: node -v
  2. 저장소 clone 또는 ZIP 해제
  3. 프로젝트 루트에서 npm ci
  4. npm run test 통과
  5. npm run dev 후 브라우저에서 한 턴 진행
  6. (선택) npm run build → dist/ 확인

운영 배포는 Vercel이 main 머지 때 올립니다. 로컬에서 제출·시연만 하면 개발 서버로 충분합니다. 대량 균형 확인은 npm run simulate -- --runs=1000입니다.

4. 환경 · 없는 것

필요불필요
Node.js 22+, npm, 최신 Chrome/Safari/Firefox, 저장소 읽기 권한 Python, Docker, DB, Redis, 클라우드 계정, Vercel 토큰, API 키, .env

앱은 정적 파일입니다. 개발 중에는 Vite가 src/를 묶어 주고, 배포 때는 dist/만 올리면 됩니다. vercel.json은 Framework Vite, Build npm run build, Output dist로 고정합니다. GitHub Pages 워크플로(.github/workflows/pages.yml)는 수동 실행 전용입니다.

.vercel/과 .env.local이 생기면 커밋하지 마세요. 이 프로젝트는 원래 환경 변수가 없습니다.

5. 필요한 패키지

package.json 기준입니다. dependencies 칸은 비어 있습니다. 설치는 npm ci(lockfile 고정)를 씁니다. 아래 버전은 범위이고, 실제 설치 버전은 package-lock.json이 정합니다.

개발용 (devDependencies)

패키지범위하는 일
vite^7.1.1개발 서버·번들. base: './'
typescript~5.8.3타입 검사. 빌드는 tsc -b && vite build
vitest^3.2.4테스트. tests/**/*.test.ts, environment node

브라우저에 따로 설치하지 않는 것

React, Vue, UI 라이브러리, 상태 라이브러리, 차트, 오디오 파일, 3D 엔진은 없습니다. 화면은 바닐라 DOM, 말은 Web Animations API, 효과음은 WebAudio 합성, 스타일은 src/styles/main.css 한 장입니다.

Node 내장만 쓰는 곳

테스트와 시뮬레이터는 node:fs 등으로 파일을 읽습니다. 추가 npm 패키지가 아닙니다.

7. 실행 흐름

index.html
  └─ /src/main.ts
        ├─ validateContent()     src/data/content.ts  (JSON·보드·퀴즈 형식 검사)
        └─ new PensionRoadApp()  src/ui/app.ts        (화면·입력·저장)

한 턴(엔진): startTurn(시장 반영) → 칸 효과·퀴즈·생활사건 → performAction(최대 2회)
            → finalizeTurn → 정산 화면
12턴 뒤: 마무리 퀴즈 ≤3 → 수령 방식 → 결과(업적·컬렉션)

난수는 시드(FNV-1a → xorshift32)라 같은 시드는 같은 주사위·시장·사건입니다. 콘텐츠는 src/data/*.json이고 코드가 숫자를 하드코딩하지 않습니다.

  • npm run lint · npm run typecheck · npm run test가 통과한다.
  • npm run dev 주소에서 제목 화면이 보인다.
  • 「바로 시작」으로 속보 → 행동 → 정산까지 한 턴이 이어진다.
