1. 범위와 면책

연금로드는 서버리스 Vite + TypeScript 교육 게임입니다. 은행 API, 로그인, 실시간 시세, 추천 엔진, CMS, 순위표는 없습니다.

  • 투자 권유·특정 회사/종목 추천 금지.
  • 정책 숫자는 src/data/policy-rules.json만 고칩니다. 기준일 2026-08-10.
  • 화면 문구는 쉬운 말을 유지하고, 법령 문장을 그대로 복사하지 않습니다.
  • 퇴직연금_브루마블형_HTML5_게임_기획안.md 등 v0.1/v0.2 기획안은 히스토리로 두고 편집하지 않습니다.

4. 실행·검증

Node.js 22 권장.

npm install
npm run dev

npm run simulate -- --runs=1000

테스트는 Vitest입니다. 매뉴얼 문자열 검사를 포함해 회귀 231개(2026-09-06, action-form.test.ts 8개 포함)입니다. 콘텐츠 검사는 validateContent()가 상품 6개, 시장 템플릿 12턴, 충격 카탈로그 6종, 국면 설정 4개, 칸 설명 24×5, 위험등급 1~5, 보드 24칸의 effect와 스포트라이트 productId를 확인합니다.

tests/market-regime.test.ts는 시드 200개로 금리 이동 턴 비율(≥50%), 빅스텝 판 비율(≥60%), 충격 슬롯 규칙, 신호 비율, ETF 기대수익(양수·예금 초과)과 표준편차(≥3.5%p)를 고정합니다. tests/balance-gate.test.ts는 전략 9종 × 100판으로 「분산·납입·리밸런싱 > 관망·집중·추격」, 위험한도 추종형의 낙폭·3별 비독점, 주사위 합–총점 무상관(|r|<0.1), newsChaser(속보 보고 갈아타기)가 balanced를 이기는 시드 ≤ 50%, 칸 효과 켬/끔의 월 연금 차이 한도를 고정합니다. 시장 상수나 턴 순서를 바꾸면 이 두 파일이 먼저 깨집니다.

10. 알려진 제한

  • 중간 저장 없음. 새로고침하면 그 판은 처음부터입니다(성향·기록만 남음).
  • 생활사건 강제 매도는 대기 중인 펀드 매수 주문을 취소하지 않습니다. 대기 매수 대금은 다음 턴에야 상품이 됩니다.
  • 시장이 이미 70%를 넘기면 위험자산 추가매수는 canBuyRiskAsset이 거절합니다. 비중을 더 키우지 않는 예금·채권 매수는 됩니다. 대기자금을 예금으로 옮겨도 비중은 거의 그대로입니다.
  • 자동 시뮬 전략은 사람 플레이를 대표하지 않습니다.
  • 은퇴 전망대의 범위는 가상 분기 20개의 p10/p90이며 실제 경로와 무관합니다. 실제 결과가 범위 밖일 수 있습니다.
  • 고스트 경로는 판 시작 때 한 번 계산하고 재계산하지 않습니다. 「그대로」만 하는 경로라 판 중간에 성향·목표를 바꿔도 IRP 경로는 같습니다.
  • 추가 생활사건은 시드 일정 사건과 같은 턴에는 나지 않으므로 한 턴에 사건 창은 최대 1개입니다.
  • 제도 안내 칸은 '제도' 카드가 모두 열린 뒤에는 이해 +1만 줍니다. 퀴즈(묶음 B)로 교체 예정입니다.
  • 금융·세무 전문가 검수와 실제 사용자 5~8명 관찰은 자동 테스트로 대체할 수 없습니다.
  • LocalStorage가 차단되면 게임은 되나 기록이 세션 밖에 안 남습니다.
