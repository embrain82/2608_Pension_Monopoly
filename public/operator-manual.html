1. 범위와 면책

연금로드는 서버리스 Vite + TypeScript 교육 게임입니다. 은행 API, 로그인, 실시간 시세, 추천 엔진, CMS, 순위표는 없습니다.

  • 투자 권유·특정 회사/종목 추천 금지.
  • 정책 숫자는 src/data/policy-rules.json만 고칩니다. 기준일 2026-08-10.
  • 화면 문구는 쉬운 말을 유지하고, 법령 문장을 그대로 복사하지 않습니다.
  • 퇴직연금_브루마블형_HTML5_게임_기획안.md 등 v0.1/v0.2 기획안은 히스토리로 두고 편집하지 않습니다.

3. 실행·검증

Node.js 22 권장.

npm install
npm run dev
npm run lint
npm run typecheck
npm run test
npm run simulate -- --runs=1000
npm run build

테스트는 Vitest, 현재 회귀 62개 전후입니다. 콘텐츠 검사는 validateContent()가 상품 6개, 시장 템플릿 12턴, 칸 설명 24×5, 위험등급 1~5를 확인합니다.

개발 서버에서 매뉴얼은 /user-manual.html, /operator-manual.html입니다.

4. 배포

백엔드 없음. npm run build 후 dist/를 정적 호스팅하면 됩니다. Vite base는 ./라 하위 경로에도 올립니다.

Vercel

  1. GitHub 저장소 embrain82/2608_Pension_Monopoly를 Vercel에 Import합니다.
  2. Framework Preset: Vite. Build npm run build, Output dist.
  3. 환경 변수는 필요 없습니다.
  4. 프로덕션 브랜치는 보통 main입니다. 이 작업 브랜치 cursor/p0-market-first-loop-5ed6는 Preview URL이 생깁니다.
  5. CLI: npx vercel login 후 프로젝트 루트에서 npx vercel --yes --prod.

vercel.json이 저장소에 있습니다. 배포 후 확인 경로:

  • / 게임
  • /user-manual.html 사용자 매뉴얼
  • /operator-manual.html 이 문서

에이전트 환경에는 Vercel 계정이 연결되어 있지 않을 수 있습니다. 그때는 저장소 소유자가 Vercel 대시보드에서 GitHub 연동만 하면 Preview/Production URL이 발급됩니다.

자동 테스트가 엔진을 잠그고, 아래는 브라우저 스모크용입니다. 375폭과 1280폭을 권장합니다.

9. 알려진 제한

  • 중간 저장 없음. 새로고침하면 그 판은 처음부터입니다(성향·기록만 남음).
  • 시장이 이미 70%를 넘긴 뒤 안전자산 매수도 canBuyRiskAsset이 거절할 수 있습니다. 대기자금으로 두는 것은 가능합니다.
  • 자동 시뮬 전략은 사람 플레이를 대표하지 않습니다.
  • 금융·세무 전문가 검수와 실제 사용자 5~8명 관찰은 자동 테스트로 대체할 수 없습니다.
  • LocalStorage가 차단되면 게임은 되나 기록이 세션 밖에 안 남습니다.

10. 출시 전 체크리스트

  • lint / typecheck / test / build 초록
  • Vercel(또는 동등 정적 호스팅)에서 게임·두 매뉴얼 URL 200
  • 면책 문구, 출처 3링크, 기준일 확인
  • Q1~Q16 스모크
  • 정책 JSON이 시행 규정과 어긋나지 않는지 담당 검수
  • 스크린샷·시드 하나를 릴리스 노트에 고정
